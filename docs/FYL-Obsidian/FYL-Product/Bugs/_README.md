# Bugs

Notas vivas de bugs detectados. Usar [[../_Templates/Template-Bug]]. Al cerrar, mover a postmortem con [[../_Templates/Template-Postmortem]] **manteniendo el mismo `BUG-NNN`**.

## Convención

- ID: `BUG-NNN` (numeración secuencial global).
- Archivo: `BUG-NNN-slug-corto.md`.
- Estado en front-matter: `abierto | en-análisis | en-progreso | resuelto | descartado`.
